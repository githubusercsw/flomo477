## 一、P1 的三个硬发现

### 发现 1：Web Crypto 不支持 MD5（已解决）
```js
crypto.subtle.digest('MD5', data)  // ❌ "Unrecognized algorithm name"
```
Web Crypto 只有 SHA 系列，而 flomo 签名强制 MD5 → **必须自带实现**。
已实现 `src/shared/core/md5.js`，单测用 Node `crypto.createHash('md5')` 交叉验证（11 个用例含中文/emoji/长文本，逐字节一致）。
踩坑：MD5 输出是**小端字节序**，用 `toString(16)` 会让结果每 4 字节反转（第一版就错了，被交叉验证抓出来）。

### 发现 2：签名要「固定参数一起签」
不能只签业务参数再把 `api_key`/`tz` 拼到 URL 上——服务端算出的 MD5 会不一致。
`buildSignedParams(business, fixed)` 把固定参数与业务参数合并后整体签名。

### 发现 3：沙盒无法访问 flomoapp.com（无法自动验证）
出网代理返回 `{"detail":"No policy rule matched the request"}`（DNS 能解析，请求被网关拒）。
→ 审计 L3「`PUT /memo` 是否返回 slug」**无法在沙盒验证**，已交付真机脚本（见 §四）。

## 三、已验证（109 项自动测试）

**签名与 MD5**：与 Node 原生 MD5 逐字节一致 · 排序/跳空保留 0 与 false · 数组 `key[]=` 形式 · 固定参数整体签名 · 端点路径编码

**客户端链路（mock fetch）**：登录带签名不带 Authorization · 原文透传服务端报错 · 无 token 判定接口变更 · 创建转义后写入 · 无 slug 返回 `slugResolved:false` · 删除签名放 query · 同步带 `include_deleted` 与游标 · 空列表即到底

**错误与重试**：`-10/-20` → `not_authenticated` · 业务错只发 1 次 · 网络错重试至 3 次 · 429 → `rate_limited` 不重试 · 非 JSON → `contract_changed`

**后台接缝**：未登录被把关中枢拦下且不发请求 · 登录成功 token/user 落盘 · 空值前端拦截 · token 失效自动清除并发通知 · 登出清干净 · 带来源拼正文

**UI**：未登录渲染表单 · 空值提交前端拦截 · 填表提交成功写入 token · 空内容/纯空格禁用保存按钮

**抓到的真实 bug**：`api-proxy.js` 用了 `set()` 却漏了 import → 登录直接失败。已被测试捕获并修复。

## 四、需要你真机验证（沙盒做不到）

### 必做：确认创建响应是否含 slug

```bash
cd flomo-extension
node tools/verify-api.mjs --email 你的邮箱 --password '你的密码'
```

脚本会依次打印：① 登录响应键 → ② **创建笔记的完整响应体** → ③ 同步首页字段 → ④ 自动删除探针笔记（软删，回收站可找回）。

**重点看 ② 的结论行**：
- `✅ 是` → 撤销/删除按计划实现
- `❌ 否` → 撤销功能砍掉，或改用 `/memo/latest_updated_desc` 取第一条的退路

脚本同时会告诉你：登录接口字段名对不对、同步游标字段名与类型、签名是否真的被服务端接受。

### 顺带确认（加载扩展后）
1. 点图标 → 弹 Popup → 显示登录表单
2. 填真实账密 → 登录成功 → Popup 自动关闭
3. 重新点图标 → 已登录，应直接开 Side Panel（智能分流生效）
4. 侧边栏里能输入并保存一条笔记（会真的写进你的 flomo）
5. 开控制台看 Network：`flomoapp.com` 请求返回 `code: 0`
