# 免真机验证机制

> 目标：把「每次改动都要真机测」变成「按需真机测」。
> 日期：2026-09-09

---

## 一、为什么以前必须真机

之前的验证手段只有两种，各有硬伤：

| 手段 | 问题 |
|---|---|
| 自编 mock 跑测试 | **mock 是我自己编的** —— 如果我对接口理解错了，mock 也跟着错，测试全绿但真机必挂 |
| 真机加载扩展 | 慢、要人工、且只能发现"已经发生"的问题 |

「请传入 timestamp」那次事故就是典型：我按文档描述理解了签名，自编的测试全部通过，真机一跑就挂。

**根因不是测试不够多，是测试用的"事实"不是真的事实。**

## 二、新机制的核心：把「事实源」换成官方抓包记录

关键发现：**沙盒里 `codeload.github.com` 是可达的**（其他站点基本被 403）。

```
https://codeload.github.com/dulk-dev/flomo-cli/tar.gz/refs/heads/main   → 200 ✅
https://raw.githubusercontent.com/...                                    → TIMEOUT ❌
https://flomoapp.com / github.com / api.github.com                        → 403 ❌
```

于是可以直接下载 flomo-cli 上游仓库，拿到两类**权威事实**：

1. **`docs/flomo-api-analysis.md`** —— 作者通过浏览器抓包 + 前端 JS 分析记录的真实请求/响应，**标注了每个端点"已验证"**
2. **`tests/test_signing.py`** —— 从真实请求中固化下来的签名向量

已固化到 `_memory/raw/flomo-cli-source/`（166KB 全量源码，含文档与测试）。

### 三层防线

| 层 | 做什么 | 抓什么 bug |
|---|---|---|
| **L2 契约守卫** | 静态比对「我们的实现」与「上游源码」 | 上游有 `timestamp` 我们没有、上游用 `json=` 我们用 form、密钥不一致…… **这类正是上次事故的类型** |
| **L3 契约回放** | 用官方抓包的真实响应驱动真实源码 | 响应解析错误（如列表结构）、字段缺失、软删识别失败 |
| **L1/L4/L5** | 纯函数 + mock 链路 + 后台 UI | 逻辑错误、接缝错误 |

### 效果

- **官方向量**：`md5(...) = e8749f38dfc1fcdd1582d34a0c7759f0`（真实抓包值），我们的实现必须逐字节一致
- **真实响应回放**：创建笔记响应**确实含 slug** → **审计 L3 有答案了，撤销功能成立**，不用再等真机
- 已实测：把上游密钥改一个字符 → 守卫立刻报警 → 还原后恢复绿色

## 三、怎么用

```bash
# 日常：一键跑全部（含环境自检 + 自动修依赖）
node tests-real/run-all.mjs

# 开工前 / 怀疑接口变了：顺带做契约漂移检查
node tests-real/run-all.mjs --sync

# 单独看契约有没有过期
node flomo-extension/tools/sync-contract.mjs          # 对比
node flomo-extension/tools/sync-contract.mjs --update # 更新本地副本
```

**共 145 项测试**（68 纯函数 + 11 守卫 + 10 回放 + 21 API 链路 + 35 后台/UI/架构）。

## 四、现在还需要真机的只剩三类

| 类别 | 原因 |
|---|---|
| **视觉观感** | 配色/间距/动效好不好看，代码测不出来 |
| **SW 真实生命周期** | 30 秒回收、事件保活 —— jsdom 模拟不了 |
| **浏览器特有交互** | 划词浮层在真实网页的定位、Shadow DOM 实际表现、右键菜单、侧边栏 |

**接口正确性已不再需要真机** —— 这是最大的变化：以前每次改 API 代码都要你手动登录测，现在跑一次命令就知道。

## 五、环境坑（已自动化处理）

沙盒的 npm 装在**全局** `/usr/local/lib/node_modules`，但 Node 裸导入只查 `./node_modules` 向上各级 —— 全局包**不在查找路径里**。而且全局包会被其他安装操作清掉（已发生两次，导致测试突然全红）。

`tests-real/ensure-env.mjs` 会在每次跑测试前自检，缺依赖就自动重装 + 建软链。已验证三种场景（软链缺失 / 全局包缺失 / 坏软链）均能自愈。

## 六、教训

> 「文档描述」和「真实实现」之间有 gap。逆向接口尤其如此 —— 文档里那句"拼成 `k=v&k2=v2&`"就是歧义来源。
> **能拿到源码就拿源码，能拿到抓包就用抓包，别信二手描述。**
