# 最终口径（唯一实现依据）

> 来源：R1–R19 十九轮调查 + 两次审计。**已剔除全部被推翻项**，按模块组织便于实现时查阅。
> 溯源请查 `decisions-history.md`。本文件更新即视为口径变更，需同步 INDEX.md 速记。
> 更新：2026-09-08

---

## A. 技术栈与工程
| 项 | 口径 |
|---|---|
| 语言 / 构建 | 原生 JS + ES modules，零构建（SW 声明 `"type":"module"`） |
| UI | 原生 DOM + CSS，零依赖 |
| 测试 | `node --test`（零依赖）；`tests/{unit,integration,fixtures}` 镜像源码 |
| 验证 | 单测 + mock 联调（仿真夹具 10–20 条，含图片/音频/软删/层级标签） |
| 目录 | `src/shared/{core,api,platform}` + `src/{background,content,ui}` |
| **依赖方向** | `core` ← `api` ← `background`；`platform` 可被任意层依赖；**UI 禁止 import `api`** |
| core 规矩 | 不许碰 `chrome.*` / 网络 → 纯函数，Node 可直接测 |
| platform 规矩 | 唯一允许碰 `chrome.*` 与 IndexedDB 的地方 |
| UI 规矩 | 不写业务逻辑，只发消息 + 渲染状态 |
| 推进 | 阶段制，一阶段一交付，验证通过才前进 |

## B. 入口与导航
| 项 | 口径 |
|---|---|
| 点图标 | **智能分流**：未登录 → 弹 Popup 登录页；已登录 → 开 Side Panel |
| 速记框位置 | 已登录时在 Side Panel 顶部 |
| 快捷键 | `Ctrl/Cmd+Shift+F`，**只注册一组**；冲突时引导用户去 `chrome://extensions/shortcuts` 自改（运行时改派做不到） |
| Popup 内容 | 多行输入 + `Ctrl/Cmd+Enter` 保存；底部入口跳 Side Panel / 设置 |
| 未登录首开 | 直接进登录页，不展示空列表 |

## C. 录入（划词 / 速记）
| 项 | 口径 |
|---|---|
| 入口 | 划词浮层 + 右键菜单「存入 flomo」+ Popup 快捷键；**悬浮球已砍掉** |
| 触发方式 | 四选项可自定义：**默认「浮出小图标」**（选中→小图标→点击展开）；另有"选中直弹"/"仅右键"/"关闭" |
| 小框字段 | 内容编辑区（常驻不可关）+ 来源开关 + 标签行 + 保存后提示条；标签行与来源开关可在设置关掉，默认全开 |
| 空内容 | **trim 后长度为 0 → 禁用保存按钮** |
| 超长 | 前端不设上限，交服务端判定，按错误码提示 |
| 长文本 | 全存 + 小框可滚动，不截断不折叠 |
| 文本转换 | 每行包 `<p>`，`#标签` 原样保留；**写入前先 `escapeHtml`**（否则纯文本化显示会吞掉 `<`、`&`） |
| 来源 | 每次询问是否附加「标题 + 链接」 |
| 保存反馈 | **轻量 toast 后关闭** |
| 撤销 | **跟 toast 同寿（约 6 秒），不落盘**；撤销 = 真删（软删）+ 提示「可在 flomo 回收站恢复」 |
| 浮层隔离 | Shadow DOM 全隔离，自带样式变量 |
| 浮层关闭 | Esc + 点外部 + 关闭按钮三重；浮层内 Tab 循环不跑到宿主页 |
| 黑名单 | 设置页可加站点黑名单（域名/通配），命中站点不渲染浮层 |

## D. 认证
| 项 | 口径 |
|---|---|
| 方式 | 仅账密 `POST /user/login_by_email`；**不做手动粘贴 token 入口** |
| Token 存储 | 只存 `chrome.storage.local`，**每次请求现读** |
| 过期（-10/-20） | **发系统通知 + 点击打开登录页**；同时清本地 token |
| 登录失败 | **原文透传服务端提示 + 错误码**，不翻译不改写；附排查引导 |
| 登录页 | Popup 内嵌（短路径）+ 独立标签页（失效重登） |
| device-id | 首次生成 UUID **持久化复用**，禁止每次随机 |
| UA | 伪装普通 Chrome，不带扩展标识 |
| -20 处理 | 引导去网页端完成验证后再回来登录 |
| 用户信息 | 登录后调 `/user/me` 存 nickname/email 供设置页显示 |

## E. 同步
| 项 | 口径 |
|---|---|
| 首次/登录后 | **全量**：分页拉（每页 200），后台静默，不阻塞 |
| 之后 | **增量**：游标 `latest_updated_at` + `latest_slug` |
| 清空缓存后 | 回到全量 |
| 进度显示 | 「已同步 N 条…」；**不显示「3/5」假分母**（cursor 分页总和不可知） |
| 定时 | `chrome.alarms`，默认 5 分钟，可设 1/5/15/30 |
| **事务** | **每页独立事务 + 游标即时落盘**（IDB 事务不可跨网络 await），中断续跑 |
| 中断提示 | **只有一条都没拉到时**才提示「上次同步未完成，点此重试」（避免 SW 正常休眠误报） |
| 软删 | 拉取必须 `include_deleted=True`；按 slug upsert |
| 冲突 | 接受 last-write-wins，不提醒 |
| 离线写 | 入 outbox，列表半透明 + 「待同步」标记 |
| **发送时机** | **三路兜底 flush**：alarms 同步前 / 打开任一 UI 时 / 保存成功后（SW 无 `online` 事件） |
| 队列 UI | 管理入口在设置页；失败项标 `failed` + 手工重试/删除 |
| 限流 | 请求串行队列 + 最小间隔 300ms；429/5xx → `rate_limited` 退避 5 分钟并暂停定时同步 |
| 同步锁 | `sync_lock` 存 storage 带时间戳，超 5 分钟自动释放 |

## F. 浏览 / 搜索 / 详情
| 项 | 口径 |
|---|---|
| 列表 | 每页 50 滚动加载；搜索结果同样分页 |
| 搜索 | 本地全量过滤 + 命中高亮，防抖 200ms；**结果复用列表当前排序** |
| 排序 | 4 种（更新/创建 × 升降），**默认更新时间倒序** |
| 筛选 | 顶部标签云，点击切换；**排序与筛选均为浏览态控件，列表顶部即时生效并存 storage**（不走设置页保存） |
| 设置页 | 只放「默认排序」作为初值 |
| 详情 | 在 Side Panel 内切换（不新开标签、不内联展开） |
| **渲染** | **一律纯文本化**（`html_to_text`），只留「含图片/音频」标记 → 无 XSS |
| 侧边栏状态 | 当前查看的 slug 落 storage，重载可恢复 |

## G. 回顾 / 推荐
| 项 | 口径 |
|---|---|
| 内容来源 | 由官方 API 决定（`/memo/notify_of_today/` 与 `/memo/{slug}/recommended?type=1`） |
| 呈现 | 回顾 = Side Panel 顶部可折叠区块，进入即加载；推荐 = 详情页底部，按需加载 |
| 相似度 | 降序 + 轻量条形/百分比，不显示原始小数 |
| 缓存 | **不缓存，实时拉取**（笔记列表与搜索仍走缓存，两条策略明确区分） |
| 离线 | 显示「离线不可用」占位，不静默隐藏 |
| 读时优化 | 允许读时复用本地缓存（命中就用，未命中才回源），不写入缓存表 |

## H. 设置页
| 项 | 口径 |
|---|---|
| 分组 | 账号 / 录入 / 同步 / 浏览 / 外观 |
| 生效方式 | **底部「保存」统一提交**（含语言）；未保存离开 → 自动保存 |
| 恢复默认 | 不做 |
| 清空缓存 | **点一次即执行**，无弹窗无确认词；**按钮旁小字说明后果** |
| 清空范围 | 仅笔记/标签/游标；**保留 token、语言、设置；outbox 不清**（否则永久丢失云端没有的内容） |
| 同步时间显示 | 相对时间 + 悬停绝对时间 |
| 外观组 | 主题（跟随系统/浅/深）+ 语言（中/英）+ 站点黑名单 + 划词触发方式 |
| 自检面板 | P0 已建 logger + 脱敏，**面板 UI 放 P6** |

## I. i18n
| 项 | 口径 |
|---|---|
| 默认 | **中文**，可在设置页覆盖（不探测浏览器语言） |
| 实现 | 自建轻量 i18n（不用 `chrome.i18n`，运行时不可切） |
| 缺键 | 回落中文 + **单测拦截**（比对中英键集合/占位符/非空） |
| 错误文案 | 服务端返回什么就显示什么，**不翻译** |

## J. 权限 / 隐私 / 视觉
| 项 | 口径 |
|---|---|
| host 权限 | 仅 `https://flomoapp.com/*`（不给 tabs、不给 `<all_urls>` 跨域权） |
| 注入范围 | `content_scripts.matches = <all_urls>`（**已接受安装警告**）；`all_frames:false`，iframe 靠右键兜底 |
| 数据 | 只存本机，零上报，代码内无第三方域名请求 |
| 日志 | 分级（debug/info/warn/error）+ 脱敏（**不记 token/密码/正文**）；设置页可开 debug |
| 主题 | 跟随系统 + 可覆盖；主色 flomo 绿 |
| 空状态 | **仅一句文案**（无插画、无引导按钮） |
| 动效 | 克制微动效 150–200ms，`prefers-reduced-motion` 下降级 |
| 无障碍 | aria-label、`:focus-visible`、键盘可达 |
| 时区 | 日期按 **UTC+8** 解析（对齐服务端 `tz=8:0`），不依赖本机时区 |

## K. 功能边界（明确不做）
对外 Agent 接口（P7 已删）· 编辑已有笔记 · 删除历史笔记（仅"刚保存的"例外）· 悬浮球 · 标签管理（首版只筛选）· 附件上传 · 多账号 · 缓存导出 · 上架商店

## L. 请求规范
```
★ 三个错了必然失败的点（已真机验证）：
  1. 每个请求必须带 timestamp（秒级 Unix 时间戳，字符串，每次现取）
  2. 签名拼接："&".join(parts) + SECRET —— 末尾**没有**多余的 &
  3. POST/PUT 用 JSON body（application/json）；GET/DELETE 用 query

签名：参数按 key 排序 → 跳过 None/""（保留 0）→ "&" 连接 → 直接追 SIGN_SECRET → MD5
     （数组用 key[]=item 且 item 排序）
请求头：Authorization: Bearer <token> / platform: web / device-model: web
        / device-id: <持久化 UUID> / User-Agent: 普通 Chrome
公共参数：timestamp / api_key=flomo_web / app_version=4.0 / platform=web / webp=1
       （tz 不是公共参数，仅 /memo/updated/ 与创建笔记时作为业务参数传入）
软删除：include_deleted 是 CLI 的**本地过滤**开关，不是服务端参数 → 本地过滤
超时：10s → timeout；网络错指数退避 3 次（2/4/8s）；API 业务错不重试
envelope：分页 {ok,data,has_more}；非分页 {ok,data,total?}；失败 {ok:false,error,message}
错误码：not_authenticated / not_found / validation_error / api_error
        / rate_limited / timeout / network_error / contract_changed / unknown_error
```
